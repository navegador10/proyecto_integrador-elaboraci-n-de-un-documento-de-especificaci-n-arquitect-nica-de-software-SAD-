# 2. Introducción
La arquitectura de software es fundamental para el desarrollo de sistemas complejos, ya que permite definir la estructura, componentes, responsabilidades y relaciones que conforman una solución tecnológica. Una adecuada arquitectura facilita el cumplimiento de los requisitos del sistema y permite abordar atributos de calidad como seguridad, disponibilidad, rendimiento, mantenibilidad y escalabilidad.

El presente proyecto tiene como propósito elaborar un Documento de Especificación Arquitectónica de Software (SAD) para un Sistema Hospitalario Digital, desarrollado en el marco de la asignatura Arquitectura del Software. El sistema busca apoyar la gestión de pacientes, historias clínicas, citas médicas, integración con laboratorios y protección de la información, garantizando una gestión eficiente y segura de los procesos hospitalarios.

El desarrollo del documento se realizará de manera incremental, siguiendo los lineamientos del Rational Unified Process (RUP) y utilizando el modelo 4+1 de Kruchten como referencia para la organización y representación de la arquitectura.

Inicialmente se definirán la visión, el alcance, los stakeholders, los módulos funcionales, los requisitos funcionales y no funcionales, y las restricciones del sistema. Posteriormente, se construirá el modelo conceptual del dominio, identificando las principales entidades, relaciones y elementos que intervienen en el sistema.

A partir de estos resultados se analizarán las decisiones arquitectónicas y se seleccionará el estilo de arquitectura más adecuado. Asimismo, se desarrollarán las principales vistas arquitectónicas: contexto, conceptual, casos de uso, lógica, implementación y despliegue, permitiendo representar el sistema desde diferentes perspectivas.

Finalmente, los artefactos serán integrados en un repositorio de GitHub, garantizando la coherencia entre requisitos, modelos, decisiones arquitectónicas y vistas. De esta manera, el proyecto proporcionará una especificación arquitectónica organizada, clara y técnicamente fundamentada, que servirá como referencia para el desarrollo y evolución del Sistema Hospitalario Digital.
