# Referencias bibliográficas

Bass, L., Clements, P., & Kazman, R. (2012). *Software architecture in practice* (3rd ed.). Addison-Wesley Professional.

Esta referencia sustenta los conceptos relacionados con arquitectura de software, atributos de calidad, decisiones arquitectónicas y relación entre arquitectura y contexto organizacional.

Kruchten, P. (1995). Architectural blueprints—The “4+1” view model of software architecture. *IEEE Software, 12*(6), 42–50.

Esta referencia fundamenta la utilización del modelo de vistas arquitectónicas 4+1 para representar diferentes perspectivas de un sistema de software.

HL7 International. (2023). *FHIR Release 5 (R5): Fast Healthcare Interoperability Resources*. https://hl7.org/fhir/R5/

Esta especificación constituye la referencia técnica para la interoperabilidad de información sanitaria mediante FHIR. El estándar define recursos y mecanismos de intercambio de información entre aplicaciones de salud.

HL7 International. (2023). *FHIR overview*. https://fhir.hl7.org/fhir/overview.html

Referencia utilizada para sustentar la utilización de FHIR como estándar para el intercambio electrónico de información sanitaria.

Congreso de Colombia. (2012). *Ley Estatutaria 1581 de 2012: Por la cual se dictan disposiciones generales para la protección de datos personales*. Diario Oficial No. 48.587. https://www.suin-juriscol.gov.co/viewDocument.asp?ruta=Leyes/1684507

Esta norma constituye una referencia jurídica para las decisiones relacionadas con protección de datos personales, confidencialidad y tratamiento de la información dentro del Sistema Hospitalario Digital. La Ley 1581 de 2012 se encuentra vigente según SUIN-Juriscol.

Rational Software Corporation. (1998). *Rational Unified Process: Best practices for software development teams*. Rational Software Corporation.

Esta referencia se utiliza como fundamento metodológico para la organización incremental del desarrollo y la documentación de los artefactos arquitectónicos.

Newman, S. (2021). *Building microservices: Designing fine-grained systems* (2nd ed.). O'Reilly Media.

Esta referencia sirve como apoyo para los conceptos relacionados con arquitectura de microservicios, separación de responsabilidades, evolución independiente de servicios y diseño de sistemas distribuidos.

Richards, M., & Ford, N. (2020). *Fundamentals of software architecture: An engineering approach*. O'Reilly Media.

Esta referencia complementa el análisis de estilos arquitectónicos, atributos de calidad, decisiones arquitectónicas y evaluación de alternativas de diseño.

International Organization for Standardization. (2011). *ISO/IEC 25010:2011: Systems and software engineering—Systems and software Quality Requirements and Evaluation (SQuaRE)—System and software quality models*. ISO.

Esta referencia se utiliza como apoyo para la identificación y análisis de atributos de calidad del sistema, incluyendo características relacionadas con rendimiento, seguridad, mantenibilidad, disponibilidad y compatibilidad.
